Before running the project, do this first:

FRONTEND:
1. Open terminal for the frontend folder and run npm install
2. You should see the node_modules folder being added
3. Test it by running, npm run dev

BACKEND:
1. Open the terminal for backend and check the requirements.txt file
2. Run this commands one by one;
   
- python -m venv myenv
- myenv\Scripts\activate
-  pip install -r requirements.txt
    
3. This should install all the dependencies you need for the backend
4. Test it by running django manage.py runserver
